# Changelog

## 0.1.0 — Initial Go port

- Added Windows drag-and-drop workflow.
- Added export/import for localization format versions 0, 1, and 2.
- Added support for `.subtitles`, `.common`, `.subtitles-systemic`, and `.web`.
- Added TXT/IDS row-count validation.
- Corrected version 0 import offsets to account for the `UNKNOWN STRING!!!\0` marker.
- Added GitHub Actions workflow for Windows amd64 release builds.
- English-language README and command-line messages.
